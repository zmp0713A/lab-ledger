# 实验台账 · 自动化测试

本目录包含三类测试样例：**正常 / 边界 / 失败**，以及一套可运行的无头浏览器回归测试。

## 怎么跑

```bash
cd tests
npm install          # 只装 jsdom 一个依赖
npm test             # 主套件（44 项）：正常 / 边界 / 失败三类样例
node run-tests-strict.mjs    # 严格校验专项（31 项）
node run-tests-report.mjs    # 报告导出与 AI 预览专项（27 项）
node run-tests-demo.mjs      # 现场演示模式专项（25 项）
node run-tests-hypothesis.mjs # AI 假设检验闭环专项（59 项）
node run-tests-persist.mjs    # 台账持久化专项（28 项）
```

六套合计 **266 项**断言；通过时输出 `✅ 通过 NN 项   ❌ 失败 0 项`，退出码 0；有失败则逐条列出（用例名 + 期望 + 实际），退出码 1。

## 原理

用 jsdom 在无头环境**真实加载 `../index.html`**（`runScripts:'dangerously'` + `resources:'usable'`，file:// URL 指向 index.html），四个 `<script>`（app.js / chart.js / tools.js / ai.js）会真正执行，然后直接调用页面里的函数（`switchExp` / `loadSample` / `recompute` / `importText` / `toolTab` / `openAI` …）。
canvas 的 `getContext` 换成假对象（jsdom 没有 canvas 实现）。

所以它验证的是**页面真的能算出这个数**，而不是代码看起来对。

## 补充两套专项测试（2026-10-07 针对审计发现新增）

### `run-tests-strict.mjs`（31 项）：严格数据校验

| 组 | 覆盖 |
|---|---|
| 单元 | `strictNumber` 接受 `1.00` / `-2.5e3` / `.5`；拒绝 `1.00abc`、`abc`、`1,2`、空串、`Infinity`、`NaN`、`1.2.3`、`--1`、`+` |
| 主表 | 填入 `1.00abc` → 校验区报「非数值」、该行结果显示 `—`、结果区不出现 `NaN` |
| 单组 | 只填 1 行 → 明确提示「只有 1 组有效数据」，不显示最终结果，不产生 `NaN` |
| 导入 | `第 2 行含 abc` → 整批拒绝并指出行号列号；表格未被改动；合法数据仍可导入 |
| 工具箱 | `1, abc, 2` → 报「第 2 个输入不是合法数字」（不再静默丢弃）；单个数字 → 提示至少 2 个 |
| 不确定度 | 负 `Δ仪` → 拒绝；正常输入 → 仍输出规范写法 |
| 线性拟合 | y 列表含 `oops` → 报非法输入 |
| AI 面板 | 切换任务后**有且仅有 1 个标签高亮**；代理未启动时提示含「代理未启动」 |

### `run-tests-report.mjs`（27 项）：报告导出与 AI 预览

| 组 | 覆盖 |
|---|---|
| 报告 | `printReport()` 真的触发打印；报告含标题/实验名/公式/原始记录/最终结果/引擎自检/异常值/“数据不出本机”声明 |
| JSON | `buildReportData()` 含实验、公式、列、6 行原始数据、计算结果与最终值、自检结果、校验摘要 |
| AI 预览 | 「填入表格」先出**候选预览**，预览阶段表格不变；点确认才写入；可取消；AI 候选值非法时拒绝 |
| 样式 | 表格横向滚动容器、窄屏断点、打印时只显示报告、`hintbox` 拼写已修 |

### `run-tests-demo.mjs`（25 项）：现场演示模式

| 组 | 覆盖 |
|---|---|
| 一键制造异常 | 对 7 个实验分别执行 `demoBreak()`：**仍保留全部 6 行（数据未被删除）**、出现异常提示、结果区无 `NaN` |
| 一键恢复 | `demoRestore()` 后不再有 `outlier-row` 标记 |
| 稳定性 | 全过程无运行时错误 |

> 演示按钮取的是**最后一个必填列**（自动跳过"次数n"这类可选记录列），因此 7 个实验都能稳定触发异常提示。

### `run-tests-hypothesis.mjs`（59 项）：AI 假设检验闭环

| 组 | 覆盖 |
|---|---|
| 检验①剔除单点 | `testDropOne` 的均值/标准差用**测试独立复算核对**；无效行号、组数不足被拒绝 |
| 检验②分段漂移 | 前半/后半均值、差值、`differenceInSD` 全部独立复算核对 |
| 检验③列相关 | 构造完美线性关系验证 `r≈1`、`r²≈1`；列越界、常数列被拒绝 |
| JSON 提取 | 纯 JSON / 带前后废话 / markdown 代码块 / 含花括号字符串均能正确提取；空数组、非 JSON、空输入返回 null |
| 完整闭环 | 假 AI 两阶段调用顺序正确（propose → conclude）；渲染含假设原文、引擎判定、检验方式、AI 结论、分工声明、人工判断提示 |
| 异常路径 | AI 不给 JSON 时给原文兜底且不再第二次调用；AI 调用失败明确报错；数据不足 3 组时拒绝运行且不调用 AI |

> 另有 `hypothesis-real-e2e.mjs`（真实端到端，需本地代理运行）：用真实 Agnes 模型跑完整闭环并断言面板渲染，已实测 9/9 通过（Agnes 提出 3 条假设、引擎逐条检验、Agnes 引用引擎数字下结论）。

### `run-tests-persist.mjs`（39 项）：台账持久化

| 组 | 覆盖 |
|---|---|
| 自动草稿 | 保存→清空→恢复一致；草稿按实验隔离（切换回来数据还在）；空表不覆盖草稿；状态行提示 |
| 项目文件 | 导出含 app/format 标识、实验名、列、6 行原始读数；导出→载入 round-trip |
| 快照兼容 | 「导出数据(JSON)」的报告快照也能作为项目文件载入还原 |
| 拒绝路径 | 垃圾文本、列数不符、非法数字、缺必填列、超出范围、未知实验名——全部整批拒绝且不改动表格 |
| 自动切实验 | 载入文件时自动切到文件所属实验并还原 |
| 报告信息/uB | 姓名/班级/日期/uB 随草稿保存并恢复；报告数据含 reportMeta 与 uncertaintyInput；CSV 带 BOM/表头/逐行结果 |

## 覆盖了哪些风险点

- **错误计算**：A 组 7 个实验逐一对比已知答案（引擎自检），任何公式/修约错误都会被发现
- **边界数据**：缺可选列（B1）、组数不足 6（B2）、临界值表超范围（B6）、修约的「五成双」规则（B5）、B 类不确定度合成（B7）
- **拒绝行为**：空表不编造（C1）、列数不符拒导入（C2）、非数值拦截（C3）、异常值只提示不删除（C4）、uB 非法锁定（C6）
- **AI 不可用**：代理未启动时明确提示而非静默失败（C5）
