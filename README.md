# 实验台账 · Lab Ledger

给高校理科实验课学生的数据处理工具——把原始读数变成「可复核的结果」，每一个数字都能追到出处，数据有问题会明确拒绝，绝不自作主张。

## 一、它解决什么问题

- 实验课后手工处理数据要 40 分钟以上，单位换算和有效数字最容易错
- 老师只能看最终结果，无法逐份复核过程
- 学生不知道自己的数据里哪一组是异常值

## 二、三个特色（差异化）

1. **结果可追溯**：每个算出来的数字旁边都有 🔍，点开可以看到它来自哪几行原始数据、用了什么公式、中间过程是什么
2. **自带引擎自检**：内置一份已知答案的数据，每次输出前回跑对照；对不上就显示「结果不可信，已锁定」
3. **会拒绝、不编造**：缺值、单位异常、超出量程、组数不足时会明确报错并指出第几行；异常值只提示不自动删除；没有数据就显示「还没有数据」，绝不编一个数字出来

## 三、快速开始

- **工具本体**：双击 `index.html` 即可，纯网页、无需安装、无需联网、数据不出本机
- **AI 助手（可选）**：双击 `启动AI代理.cmd`（保持黑窗口开着），然后在页面顶栏点「🤖 AI 助手」。
  它需要本机已安装 Agnes Harness（AGH）；没装也不影响工具本体使用，AI 面板会提示代理未启动。

## 四、功能清单

### 7 个实验（每个都预置示例数据，点「载入示例数据」即可看到效果）

1. 单摆测 g —— g = 4π²L/T²
2. 伏安法测电阻 —— R = U/I
3. 分光计测棱镜折射率 —— n = sin((A+δ)/2)/sin(A/2)
4. 滴定测盐酸浓度 —— c(HCl) = c(NaOH)·V(NaOH)/V(HCl)
5. 惠斯通电桥测电阻 —— Rx = R·l₁/l₂
6. 示波器测频率 —— f = 1000/(时基×格数)
7. 自由落体测 g —— g = 2h/t²

说明：加一个新实验只需要在 app.js 的 EXPS 数组里加一份配置（列定义、公式、自检答案），不需要改引擎代码。

### 12 个工具（工具箱）

单位换算（长度/质量/面积/体积/时间/压力/能量/功率/角度/温度）、统计·方差、线性拟合、有效数字修约（四舍六入五成双）、相对误差、SI 词头、浓度·稀释、逐差法、不确定度、格拉布斯异常值检验、溶液配制、几何体积

### 表格实时反馈

每一行右侧会实时显示该行算出的结果；格拉布斯检验判定为可疑的行会整行标黄并给出提示（但不删除数据）。

### 严格数据校验（拒绝伪数字）

输入按**完整数字**校验：`1.00abc`、`1,2`、`Infinity`、`NaN`、`1.2.3` 这类都会被判为非数值并指出所在行；Excel 粘贴导入逐格校验，任何一格不合法就**整批拒绝**、不改动已有数据。
工具箱同样不再"静默丢弃"坏输入——例如统计工具输入 `1, abc, 2` 会明确报出「第 2 个输入不是合法数字」。
只有 1 组有效数据时不再产生 `NaN`：结果区明确提示"只有 1 组有效数据"，不发最终结果。

### 导出报告与数据

- **导出报告(PDF)**：生成一份完整报告（实验名、公式、原始记录、数据校验、计算结果与最终值、引擎自检、疑似异常值、生成时间）后再打印/存 PDF，报告页脚声明"数字全部由本工具确定性代码计算、数据未离开本机"。
- **导出数据(JSON)**：导出机器可读的同一份数据，便于复核与留档。

### 保存与载入（台账两层持久化）

- **自动草稿（防丢）**：原始读数自动存进本机浏览器的 localStorage，误关页面/刷新后自动恢复；切换实验回来数据还在；**空表不会覆盖已有草稿**（误清空也能救回）。
- **💾 保存项目 / 📂 载入项目**：把全部原始读数存成 `.ledger.json` 文件，可移交老师、归档、换电脑继续做；载入时**逐格严格校验**，任何一格不合法就整批拒绝、绝不动现有表格。之前「导出数据(JSON)」的报告快照也能直接载入继续编辑。

### 现场演示辅助

顶栏提供两个按钮，便于在几分钟内稳定演示"会拒绝 + 只提示不删除 + 可追溯"：

- **🎬 演示：制造一个异常**：载入示例数据后，把第 3 行的最后一个必填列改成一个明显偏离的值 → 立刻出现校验/异常提示（**数据不会被删除**）
- **↺ 恢复示例**：一键还原成干净的示例数据

### AI 助手（5 个功能 + 1 个科学闭环）

解释校验报错 / 写结论与误差分析草稿 / 整理乱数据成规范表格 / 生成新实验模板 / 自由提问

**🔬 AI 假设检验闭环（核心特色）**：点「提出假设并检验」后，分三步自动完成——

1. **Agnes 提出假设**：阅读引擎给出的客观事实（原始数据、统计量、可疑组），提出 2~3 条可检验的物理假设（如"第 3 组周期偏小源于计时起点提前"），只允许选用四种已实现的检验方式；
2. **确定性引擎检验**：剔除单点（`drop_one`）/ 前后半段漂移（`split_half`）/ 列相关性（`column_corr`）/ **物理模型检验（`model_fit`：拟合 T²∝L 由斜率反推 g，与标准值比对）**——检验过程与全部数字由本工具代码计算，可复算、可追溯；
3. **Agnes 依据数字下结论**：逐条说明假设被支持还是被否定，引用引擎给出的具体数字，最后声明"是否剔除由人决定"。

分工是硬性的：**Agnes 决定"检验什么"，引擎决定"检验结果是什么"**；数字不经过 AI，AI 的话也不能自动改动数据。

**AI 护栏（这是设计的一部分）**：数字一律由本工具的确定性代码算出，AI 只负责写文字和解释；
所有 AI 输出都标注「系统草稿 · 需人工确认」；AI 不确定时会说不确定。
「整理乱数据」的结果**先显示候选预览、由你确认后才写入表格**（可取消），AI 不会直接改动数据。

## 六、换一台电脑怎么用（便携版）

### 情况一：只用数据工具（7 个实验 + 12 个工具）
工具本体是纯静态网页，零依赖：把 `lab-data-assistant` 文件夹（约 240 KB）拷到任何 Windows 电脑，
双击 `index.html` 就能用 —— 不需要安装 Node、不需要 AGH、不需要联网。
已实测：在另一个 Windows 用户账户下、从 D 盘目录运行，44 项自动化测试全绿。

### 情况二：还要用 AI 助手（一次性配置，之后双击即用）
便携包自带 Node 运行时和 AGH 运行包，只需在目标电脑上做一次配置：

1. 双击「首次配置AI.cmd」，浏览器会自动打开 AGH 设置页面
2. 在设置界面里点「添加账户」，供应商选 Agnes AI，填入 API Key（赛事群里领的那个），保存
3. 以后双击 `启动AI代理.cmd` 即可 —— 代理会自动找到刚才配置好的账户

已实测（本机模拟新电脑）：便携包能启动官方配置界面、账户配置能正确保存到系统默认目录、
代理能自动发现该目录并正常调用 AI 助手。

### 为什么不能在打包时把 Key 一起带走
AGH 把 API Key 放在受系统权限保护的私有目录里，且密钥文件本身与生成它的机器绑定，
复制到别处会失效（实测报 `The credential store is unavailable`）。这是 AGH 的安全设计，
所以 Key 只能由用户本人在每台机器上录入一次，切勿把 Key 打进提交材料。

### 查找优先级与自检
代理按顺序查找运行环境：`ai-config.json` 配置 > 环境变量（`AGH_NODE`/`AGH_CLI`/`AGH_HOME`）>
便携包自带目录 > 系统默认 `~/.agh`。
任一项缺失时不崩溃，会打印中文诊断；`GET /api/doctor` 可查看三项路径的取值与来源。

### 已知边界（诚实说明）
- 目标系统需为 Windows x64（AGH 含 Windows 专用原生模块，只依赖系统自带 DLL，无需额外运行库）。
- 工具本体已在本机换目录、换账户等条件下实测；AI 部分已在本机模拟新电脑条件下走通上述配置流程；
  真机跨电脑尚未实测，但该流程与 AGH 官方文档一致。

## 七、技术实现

- 纯前端：HTML + 原生 JavaScript，无框架、无第三方运行库、不联网
- 计算全部是确定性代码（可复算）；AI 只做文字生成，不参与任何数值计算
- 本地代理 ai-proxy.mjs：把网页请求转发给本机的 Agnes Harness（`agh -p --standalone`），每次调用都会往 `ai-log.jsonl` 追加一行记录（时间/任务/耗时/成功与否），作为可核查的运行日志
- 运行底座：Agnes Harness + Agnes 模型（agnes-3.0-flash）

## 九、已知限制（诚实写）

- AI 功能需要本机安装 Agnes Harness 并启动本地代理；不做联网直连
- 拍照识别尚未实现，输入方式是填表或从 Excel 粘贴导入
- AGH 目前是 pre-alpha 版本，在 Windows 上偶尔需要重启
